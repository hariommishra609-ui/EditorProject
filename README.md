# Editor2015 – Java Code Editor

## 📌 About the Project

**Editor2015** is a desktop-based text editor and Java programming tool developed using Java Swing. It provides a graphical user interface (GUI) for writing, opening, editing, saving, compiling, and running Java source files.

The application is designed to make basic Java programming tasks easier through a menu-driven interface.

## ✨ Features

- **New File:** Create a new Java source file by entering a class name.
- **Open File:** Open and edit existing files.
- **Save:** Save changes to the current file.
- **Save As:** Save a file with a new name or location.
- **Print:** Menu option provided for printing.
- **Exit:** Close the application.
- **Cut, Copy, and Paste:** Perform basic text-editing operations.
- **Delete:** Remove selected text.
- **Select All:** Select all text in the editor.
- **Time & Date:** Insert the current date and time.
- **Text Color:** Change the text color using a color chooser.
- **Compile Java Code:** Compile Java source files using `javac`.
- **Run Java Programs:** Execute compiled Java programs using `java`.
- **Output Panel:** Display compilation messages, program output, and errors.
- **About Editor:** Display project information.

## 🛠️ Technologies Used

- Java
- Java Swing (`javax.swing`)
- AWT (`java.awt`)
- Java Event Handling
- File Handling and I/O
- Java Runtime and Process Execution
- Git and GitHub

## 💻 Requirements

- Java Development Kit (JDK) installed
- A Windows or other desktop environment that supports Java Swing
- Java compiler (`javac`) available through the system PATH

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/hariommishra609-ui/EditorProject.git
```

### 2. Open the Project Folder

```bash
cd EditorProject
```

### 3. Compile the Application

Make sure `Editor2015.java` is present in the current directory.

```bash
javac Editor2015.java
```

### 4. Run the Application

```bash
java Editor2015
```

The Editor2015 desktop application should open in a new window.
